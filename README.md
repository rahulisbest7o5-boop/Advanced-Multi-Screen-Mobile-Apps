# Advanced Multi-Screen Mobile App

This project is a multi-screen mobile application built using React Native, Expo, TypeScript, and Expo Router.

The application is inspired by food delivery apps and allows users to navigate between different screens using a bottom tab navigation.

## Features

- Home screen with restaurant information
- Restaurant categories and services
- Horizontal filter options
- Map screen with pickup locations
- Search functionality
- Cart screen
- User profile screen
- Bottom tab navigation
- Interactive buttons and alerts
- Reusable React Native components

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- Ionicons

## Project Structure

- `app/` - Contains the main application screens and navigation
- `src/components/` - Contains reusable UI components
- `assets/images/` - Contains images used throughout the application
