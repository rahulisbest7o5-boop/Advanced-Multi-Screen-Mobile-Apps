
## Uber Eats Style Multi-Screen App



## Project Overview
This project is a food delivery app prototype inspired by the Uber Eats mobile interface. It is built with Expo, React Native, and TypeScript. The project focuses on recreating related screens, organizing reusable components, and connecting screens with navigation.

## Navigation
Expo Router provides bottom tab navigation between Home, Map, Search, Cart, and Profile. The layout file configures the navigation, and each screen is defined in its own route file.
